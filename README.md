## Cấu trúc

```
index.html              trang chủ, danh sách bài viết
cover.png               ảnh bìa trang chủ khi chia sẻ link
.nojekyll               để GitHub Pages phục vụ file tĩnh nguyên trạng
chuong-trinh/
  <ten-chuong-trinh>/
    index.html          trang giới thiệu chương trình
    cover.png           ảnh bìa 1200x630
    slides/             trình xem bản xem trước (ảnh slide, PDF xem trước)
bai-viet/
  <ten-bai>/
    index.html          nội dung bài
    cover.png           ảnh bìa 1200x630 cho thẻ xem trước
```

Mỗi bài một thư mục riêng, file đặt tên `index.html` để địa chỉ gọn và không đổi khi sửa nội dung.
